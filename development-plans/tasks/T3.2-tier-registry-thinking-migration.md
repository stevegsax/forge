## Problem

The forge and pbook model-tier maps are copies that have already drifted:
forge pins the stale legacy `claude-sonnet-4-5-20250929` while pbook's
worker default `claude-3-5-sonnet-20241022` is retired. The current Sonnet
is `claude-sonnet-4-6` (verified), on which `budget_tokens` is deprecated
in favor of adaptive thinking. One registry in the platform library ends
the drift; the thinking migration is a deliberate latency/cost behavior
change that must be made explicit.

retired). Migrate ThinkingConfig: `budget_tokens` is deprecated on 4.6 →

latency/cost behavior change). Delete forge/models.py:82-105 copy and all

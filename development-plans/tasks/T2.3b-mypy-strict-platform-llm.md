## Problem

Both review plans independently converged on mypy strict + 85% gates
everywhere in the monorepo. Forge already has strict mypy; the other
packages do not. The LLM side of `sax-platform` (inherited from sax-llm)
currently ships with only a 25% coverage gate and no strict typing, yet it
is the provider abstraction both apps call through. One task per package
keeps each strictness flip independently mergeable.

This is the second of four split tasks from the source's combined
T2.3a–d entry; siblings are
[T2.3a](T2.3a-mypy-strict-platform-contracts.md),
[T2.3c](T2.3c-mypy-strict-ocr.md), and
[T2.3d](T2.3d-mypy-strict-pbook.md).

## Scope

Enable mypy strict for the sax-platform llm side (the modules inherited
from sax-llm: provider abstraction, output type registry, batch response
parsing) and the remaining sax-platform modules not covered by
[T2.3a](T2.3a-mypy-strict-platform-contracts.md), fixing all resulting
errors. Forge already has strict mypy and is out of scope.

## Development Notes

**2026-07-16 — baseline.** 44 strict errors, dominated by missing
generic type args. anthropic/mistral SDKs ship typed clients, so no
`ignore_missing_imports` override is expected (unlike boto3 in T2.3a).

**2026-07-16 — all 44 fixed; zero ignores, zero overrides.** One
narrowly-scoped commented `cast` at the Anthropic batch boundary
(`list[batch_create_params.Request]` — the shape is validated by
construction in `build_batch_request`; threading the SDK's TypedDict
through the cross-provider pipeline was out of scope). Substantive
finds: typing `get_anthropic_client` surfaced three hidden issues in
anthropic.py, including an aliased `entry.result.type` comparison that
defeated mypy's tagged-union narrowing — now compared inline, so the
succeeded-branch `.message` access type-checks with no cast. mistral's
`_download_file_content(client: object)` became `client: Mistral`,
cascading away an `attr-defined` and both `no-any-return`s.
`make gates` fully green: mypy 56+9+7 files, 6/6 contracts, all five
suites; pbook cross-check (imports sax_llm) 347 passed.

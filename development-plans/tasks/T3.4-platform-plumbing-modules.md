## Problem

Generic plumbing is duplicated and scattered across the packages: three
`_LOCAL_RETRY` copies, ocr's own `persist.py`, 14+ point-of-use env reads,
and Temporal/DB/embedding helpers split between forge-contracts and
sax-llm — two package identities the one-lib topology adjudication
retires. The review also verified that psycopg does **not** auto-disable
prepared statements on Supabase's transaction pooler, so the engine
factory must handle that explicitly.

## Scope

`sax_platform.temporal` (connect_temporal with mTLS, run_worker scaffold
with sandbox passthrough + pydantic converter + graceful shutdown,
LLM_RETRY/DB_RETRY/IO_RETRY presets, `classify_llm_error` (typed SDK
exceptions first, message markers fallback, unit-tested),
`heartbeat_during`, persist_block + **public** retry presets);
`sax_platform.db` (engine factory with pooler detection — **set
`prepare_threshold=None` when port 6543**; run_migrations;
insert_or_ignore; UTCDateTime; s3_blobs); `sax_platform.embeddings`
(Embedder protocol + OpenAIEmbeddings, frozen EmbeddingResult,
base64-float32 codec); `sax_platform.config` (frozen pydantic-settings
groups — the only env readers; existing env names kept as aliases);
`sax_platform.logging`. Retire the forge-contracts and sax-llm package
identities; delete ocr/persist.py + the three `_LOCAL_RETRY` copies.

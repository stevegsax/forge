# T5.4 — Split the monolith

**Status:** NOT STARTED

## Problem

`workflows.py` is a 1,861-LOC monolith carrying the step pipeline three
times, the gather twice, and duplicated init/persist/dispatch blocks —
roughly 1,100 LOC of measured source duplication. With T5.1–T5.3 landed,
the workflow classes can collapse to thin drivers over the shared blocks,
and (after Phase 4) they should retain no signal-handling state at all.

## Scope

`workflows.py` (1,861 LOC) → package:

- `task.py` (~150 LOC driver), `subtask.py` (~60 LOC), `blocks/`,
  exploration block as a free function.
- RunSettings (frozen) threaded as a parameter.
- Workflow classes end with **zero** signal state and no duplicated
  init/persist/dispatch blocks.

## Acceptance Criteria

- [ ] ~1,100 LOC of source duplication gone (measure).
- [ ] All behavioral tests green.
- [ ] Workflow classes end with **zero** signal state and no duplicated
  init/persist/dispatch blocks.

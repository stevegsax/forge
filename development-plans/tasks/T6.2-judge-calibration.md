**Status:** NOT STARTED

## Problem

Extraction noise runs ~30% unvalidated per agent-memory research, so an
LLM judge gates which extracted entries survive. But the T6.3 migration
sweep would run that judge over the whole backfilled corpus — and an
uncalibrated judge would demote the corpus and seed the eval goldens with
its own errors. Calibration against hand-graded cases must therefore land
before the sweep is allowed to apply anything.

## Scope

Suite B — ~40 hand-graded cases including 10 generic-advice traps (~2h
human work; the one irreducible manual task); judge = CLASSIFICATION
tier, four binary checks (grounded / specific / non-generic / actionable).

## Acceptance Criteria

- [ ] ≥85% agreement, 100% trap rejection — **gates the T6.3 sweep**.
  (Sequencing fix from the cross-review: never run an uncalibrated judge
  over the corpus.)

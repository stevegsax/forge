## Problem

Blocking `subprocess.run` + file I/O inside async activities freezes workflow
task processing and defeats heartbeats (validate.py `_run_command`, git.py via
git_activities, providers.py run_tests/ruff/git handlers, code_intel
discovery).

## Scope

- Route every such call through `await asyncio.to_thread(...)`.
- Restore `_VALIDATE_HEARTBEAT` to 60s as a real crash detector.

## Problem

1. **Double application under retry.** `write_output` applies edits
   file-by-file, writing each to disk inside the loop
   (`activities/output.py:459-474`). `_WRITE_RETRY`
   (`workflows.py:128-131`) retries the whole activity on transient
   `OSError`, so files edited before the failure are re-read and
   re-edited on retry. Reproduced: an insert-style edit (replace contains
   search) applied twice silently duplicates the inserted line; a plain
   replace re-applied raises non-retryable `EditApplicationError`,
   failing the workflow after paid LLM calls. Ordinary disk pressure
   converts a recoverable transient into silent file corruption that
   flows into validation and commit.
2. **Raw-string mutual-exclusion guard.** The files/edits overlap check
   intersects raw LLM-supplied path strings (`output.py:448-453`) while
   both resolvers call `.resolve()` — so `a.py` vs `./a.py` (or
   `sub/../a.py`) bypasses the invariant; because new files are written
   before edits are resolved (`:459-474`), the edit then passes
   `resolve_edit_paths`' `is_file()` check against the just-created file
   and is applied on top of freshly generated content.

## Scope

- Compute all edited contents in memory before the first disk write; on
  retry, detect already-applied edits (search absent but replace present
  → idempotent skip) instead of re-applying or raising.
- Compare resolved paths in the files/edits mutual-exclusion guard (the
  resolvers already compute them); note that resolved-path comparison
  alone still misses APFS case variants.
- Property-based (hypothesis) tests over the pure matching/application
  functions — the textbook property target per test-strategy.md:67
  (cross-noted in T5.5; whichever lands first owns them).

## Acceptance Criteria

- [ ] Regression test: activity failure between file writes followed by a
      Temporal retry produces the same bytes as a single clean run (no
      duplicated insertions, no spurious `EditApplicationError`).
- [ ] The same file spelled two ways in `files` and `edits` is rejected
      before any write.
- [ ] Property tests over search/replace matching and application run in
      the default suite.

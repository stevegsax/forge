## Problem

Both review plans independently converged on mypy strict + 85% gates
everywhere in the monorepo. Forge already has strict mypy; the other
packages do not. The contracts side of `sax-platform` is the sandbox-light
wire-model surface every other package imports, so strict typing here
protects all consumers. One task per package keeps each strictness flip
independently mergeable.

This is the first of four split tasks from the source's combined
T2.3a–d entry; siblings are
[T2.3b](T2.3b-mypy-strict-platform-llm.md),
[T2.3c](T2.3c-mypy-strict-ocr.md), and
[T2.3d](T2.3d-mypy-strict-pbook.md).

## Scope

Enable mypy strict for the sax-platform contracts side (the modules
inherited from forge-contracts: wire models, persist_block, s3_blobs,
Temporal connect helper, DB helpers, constants, batch_jobs schema), fixing
all resulting errors. Forge already has strict mypy and is out of scope.

## Development Notes

**2026-07-16 — baseline.** 37 strict errors; the 14 `arg-type`s make
this the most substantive of the three flips so far (ocr passes real
values across the forge-contracts SPI and Temporal dataclasses).

**2026-07-16 — all 37 fixed; zero ignores.** The store.py bulk (23
errors) fell to one pattern: SQLAlchemy stubs type `Model.__table__`
as `FromClause`, so module-level typed `sa.Table` handles replaced
every `__table__` reference — the identical idiom forge's own store.py
already uses. Workflow files use explicit variable annotations on
string-name `execute_activity` calls (temporalio's string overload
returns `Any`), matching forge's idiom. One honest micro-deviation
from "typing-only": alembic/env.py gained a `None`-guard before
`create_engine`, copied verbatim from forge's env.py — unreachable in
practice (`run_migrations()` always sets the URL), and it fails one
line earlier with a clearer error. `make gates` fully green: mypy
56+9+7+15 files, 6/6 contracts, all five suites (ocr ticked up to
93.71%).

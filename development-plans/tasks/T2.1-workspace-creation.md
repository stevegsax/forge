# T2.1 — Monorepo workspace in forge (incremental absorption)

**Status:** IN PROGRESS
**Phase:** 2 — Monorepo (forge, D98)
**Repos:** forge (becomes the monorepo); pbook (absorbed this increment);
sax-llm, forge-contracts, ocr (later increments)
**Depends on:** Phase 1 complete (T1.0–T1.8)
**Last updated:** 2026-07-16

## Problem

Both redesign plans converged on a uv-workspace monorepo: single lock,
per-package pyprojects and tests, and archived old repos with pointer
READMEs. Phase 1 (T1.0) made the question urgent: uniform editable path
sources entangle the sibling locks — forge@phase-1 cannot resolve against
pbook@main — so the repos can no longer version independently even if we
wanted them to.

**Rewritten 2026-07-16 per D98:** there is no new `sax` repo. Forge itself
is the monorepo; siblings are absorbed incrementally via git-filter-repo
subdirectory rewrites, pbook first. This dissolves the original task's
open "work-queue home" question — forge and `development-plans/` survive
as the root. D87's substance (one root `uv.lock`, filter-repo over
subtree, pinned-tag uvx rule, gated 3.14 bump) carries over unchanged.

## Scope

**Increment 1 (this task's active work):** absorb pbook into `apps/pbook`
with full history (tags renamed `v*` → `pbook-v*`; the disposable
`diataxis/` Hugo site excluded from imported history); convert the forge
root to a uv workspace; fix the deploy machinery that assumed a pbook
sibling checkout; retruth the docs; tag `pbook-v0.2.2`; repoint
skill-pbook.

**Later increments (tracked here, not yet started):**

- sax-llm + forge-contracts → `libs/` (unblocks Finding A — see below —
  and Phase 3's `sax_platform` consolidation).
- ocr → `apps/ocr`.
- Python 3.14 bump: own commit, gated on a fresh wheel-matrix check at
  execution time (unchanged from the 2026-07-08 amendment).

**Finding A (design gate, recorded in D98):** the end-state skill
invocation `uvx --from git+…forge.git@<tag>#subdirectory=apps/pbook`
cannot resolve until sax-llm is absorbed — a fresh uvx clone of forge has
no `../sax-llm` sibling to satisfy the root's editable path source. The
skill pins the interim form
`git+https://github.com/stevegsax/pbook.git@v0.2.1` until then.

## Plan

One commit per step on branch `T2.1-pbook-workspace` from forge@main.
Runtime behavior must not change: no file under `src/forge/` or
`src/pbook/` is modified; both Temporal workers, queues, and the
cross-queue coupling stay as-is (Phase 6 owns their future).

0. **Prerequisites:** phase-1 merged to main in forge/pbook/sax-llm;
   clean trees; podman machine up; `uvx git-filter-repo`; pbook suite
   green at main pre-prep; record `PBOOK_MAIN_SHA` and forge main tip.
0.5. **pbook prep commits (on pbook main — no active users):** drop
   `[tool.uv.sources]` + `uv.lock`, bump 0.2.1 → 0.2.2, CLAUDE.md truth
   pass. The imported tree then needs no post-merge edits.
1. **Process-first docs commit (forge):** D98 appended; this file
   rewritten; TASKS.md Phase 2 retitled.
2. **filter-repo rehearsal (throwaway clone):**
   `uvx git-filter-repo --path diataxis --invert-paths
   --to-subdirectory-filter apps/pbook --tag-rename ':pbook-'`
   (selection before rename — order is load-bearing). Verify commit
   count, all files under `apps/pbook/`, no diataxis in history, tags
   renamed with annotations preserved, `git log --follow` crosses the
   rewrite. **Rollback criterion:** everything is branch-local until the
   owner pushes — on failure delete the scratch clone, `git branch -D
   T2.1-pbook-workspace`, delete fetched `pbook-v*` tags; forge main and
   the real pbook repo untouched (filter-repo only ever runs on
   throwaway clones).
3. **History merge:** fetch the filtered clone as a temporary remote;
   `git merge --allow-unrelated-histories --no-ff` (forge has zero tags —
   no collision).
4. **Workspace conversion (root pyproject only):**
   `[tool.uv.workspace] members = ["apps/pbook"]`;
   `pbook = { workspace = true }`; sax-llm/forge-contracts stay editable
   path sources at the root; `uv lock && uv sync`; review the lock diff.
5. **Deploy fixes:** bootstrap (add forge-contracts clone, drop pbook
   clone, migrate from the forge checkout, fail-fast on unset
   `PBOOK_DATABASE_URL`); pbook-worker.service (WorkingDirectory →
   forge checkout, drop `PBOOK_DB_PATH`, tighten ReadWritePaths);
   fetch-secrets.sh (emit `PBOOK_DATABASE_URL` from SSM
   `SUPABASE_PBOOK_DB_URL`); terraform (drop `pbook_ref`/`PBOOK_REPO_URL`
   plumbing; keep `with_pbook`).
6. **Docs truth pass:** forge CLAUDE.md (workspace member + command
   discipline); DEPLOYMENT.md (pbook-as-sibling story rewritten;
   Postgres-only); TOC.md pointer; CHANGELOG row; this file's notes;
   local AGENTS.md.
7. **Tag `pbook-v0.2.2`** (annotated; continues the renamed series).
8. **skill-pbook rewrite (separate repo):** pin the interim uvx form
   after the V10 gate confirms Finding A.

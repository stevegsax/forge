## Problem

Both redesign plans independently converged on a uv-workspace monorepo:
single lock, per-package pyprojects and tests, CI from zero, and archived
old repos with pointer READMEs. Today the five repos version independently
— forge pinned siblings by git tag while ocr used editable paths, so the
two sides of one runtime wire contract could silently run different
versions. The merged plan adjudicated the import mechanics (git-filter-repo
over shallow subtree: total history is ~8.7MB, so subtree's savings are
immaterial while filter-repo preserves blame and `git log --follow`) and
the Python version (3.14 standard GIL, wheels verified).

## Scope

Create the `sax` repo; import all five repos via **git-filter-repo
subdirectory rewrite** (full history preserved — verified total history is
only ~8.7MB; subtree's savings are immaterial) into `libs/sax-platform`
(start from forge-contracts + sax-llm merged side-by-side; real
consolidation happens in Phase 3) and `apps/{forge,ocr,pbook}`; root
`pyproject.toml` with `[tool.uv.workspace]`; all sibling deps
`{ workspace = true }`; single `uv.lock`; **`.python-version` = 3.14
standard GIL** (wheels verified for
temporalio/psycopg-binary/pgvector/pymupdf/grimp/anthropic/openai; do NOT
use 3.14t); archive the old repos with pointer READMEs; rewrite CLAUDE.md's
cross-project section.

### Amendments (2026-07-08)

This task bundled three independent risks; de-risk as follows:

- **Split the Python bump.** The workspace lands on the current Python pin
  first; the 3.14 jump is a separate follow-up commit gated on a fresh
  wheel-matrix check at execution time. The 2026-06-10 verification was
  point-in-time and its external evidence is lost.
- **Rehearse the import.** Run git-filter-repo into a throwaway target
  first; verify blame, `git log --follow`, and tags survive; document a
  rollback criterion before the real cutover.
- **Decide the work queue's home before archiving.** TASKS.md, PROCESS.md,
  and the task files live in forge, which this task archives — where
  T2.2–T8.4 are tracked from must be decided and documented first.
- **Precondition:** the `ocr` repo is not checked out under `~/repos-sax`
  (verified 2026-07-08) — locate or clone it before the import.

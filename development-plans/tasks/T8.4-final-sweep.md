CLI tests that patch implementation paths by string both fragile and
potentially pointing at deleted modules. The migration then needs a
single closing gate: every package verified green through one command
from the workspace root, and the result tagged as a release.

cycles deferred as "sweep fodder." Without an inventory here, those items
exist only in archived reports and would be invisible to whoever executes
the sweep — the amendment below is that inventory.

# Requirements Worked Examples

These examples show the autonomous-agent requirements standard as a complete, reviewable package.

## Inspira

`Inspira` is a toy web application that displays a randomly selected inspirational quote on each
page refresh. Quotes are stored in a local text file.

- [inspira.feature](inspira.feature) — behavioral examples only
- [inspira.core.md](inspira.core.md) — source-of-truth requirement core
- [inspira.review.md](inspira.review.md) — completed review record
